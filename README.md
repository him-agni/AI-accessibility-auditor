# Clarity

Clarity is an AI-assisted accessibility scanner interface for one public webpage at a time. It turns grouped automated findings into a plain-language report with element evidence, authoritative WCAG links, and cautious fix suggestions.

## Current release

Submitted pages are really scanned. Cloudflare Browser Rendering opens the URL in a headless Chromium, `axe-core` runs against the rendered DOM, and what it reports becomes the report. Remediations are generated from those findings by a schema-validated model call. If a scan cannot run, the audit fails and says so — the product never invents findings.

A scan is four passes: axe at desktop, a keyboard walk that presses Tab for real to find focus traps and missing focus indicators, axe again at a 390px mobile viewport, and a reflow measurement at 320px. The last three are best-effort — if one fails the desktop results still stand, and the scan logs what each pass did.

Findings come back in two tiers. **Violations** map to a WCAG 2.2 A/AA success criterion and are the only ones counted in the report's totals. **Advisory notes** are axe best-practice rules — real problems worth fixing, but not WCAG failures — and are listed separately so they never inflate a score.

The product never describes an automated scan as certification. Every report states that manual testing and assistive-technology evaluation are still required.

## Run a scan

```bash
npm run dev
```

`wrangler dev` starts a real local Chromium for the browser binding, so scanning works without a Cloudflare account. Open `http://localhost:3000` and submit any public URL.

## Run locally

Requirements: Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Fix generation

Remediations are generated by Google Gemini through a provider-neutral interface in `lib/fixes`. To enable it:

```bash
cp .dev.vars.example .dev.vars
# add a free key from https://aistudio.google.com/apikey
```

`.dev.vars` is gitignored. Without a key the product still works — every report falls back to deterministic axe and WCAG guidance, labelled as such. The same fallback covers API errors, timeouts, and unusable output, so a report is never partial.

One model request covers an entire audit rather than one per rule group, which keeps a scan inside the free tier's per-minute limits.

## Data

Cloudflare D1 stores audit records and supports the issue-group, occurrence, and fix-suggestion model. Generated migrations are in `drizzle`. Anonymous results expire after seven days and submissions are limited to three per hour per request fingerprint.

```bash
npm run db:generate      # regenerate migrations from db/schema.ts
npm run db:migrate:local # apply to the local Miniflare D1
npm run db:migrate       # apply to the remote D1
```

## Deploy

The product runs on Cloudflare Workers. `wrangler.jsonc` is the single source of bindings — the Vite plugin and `wrangler deploy` both read it, so local dev and production cannot drift.

First-time setup:

```bash
npx wrangler d1 create clarity-accessibility-scanner
# copy the printed database_id into wrangler.jsonc
npx wrangler secret put GEMINI_API_KEY   # optional; omit to run on deterministic guidance
npm run db:migrate
```

Then:

```bash
npm run deploy
```

`npm run deploy` builds and deploys `dist/server/wrangler.json`, the config Vite emits with the bindings resolved. Add `--dry-run` to that command to validate bindings without shipping.

## Scanner boundary

Every page is treated as untrusted. The scanner validates the submitted URL, re-validates the destination of every request the page makes, re-checks the URL it actually landed on after redirects, dismisses dialogs, bounds every stored snippet, and enforces navigation, axe, and whole-job timeouts. Cloudflare owns the browser isolation.

One gap remains: hostnames are checked, but their resolved addresses are not, so DNS rebinding is not covered. See `HANDOFF.md`.

The scanner presses Tab, but never clicks, submits a form, or dismisses a banner. It will not interact with a page it does not own beyond keyboard navigation.
